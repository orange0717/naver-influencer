# N인플 자동 동기화 확장 프로그램

네이버 인플루언서 페이지의 팔로워/팔로잉을 [ninfle.kr](https://ninfle.kr) 대시보드로 자동 동기화하는 크롬 확장 프로그램입니다.

## 무엇이 다른가요?

기존 북마클릿 방식 대비:

| | 북마클릿 | 확장 프로그램 |
|---|---|---|
| 설치 | 드래그 (어려움) | 폴더 선택 1회 |
| 매일 사용 | 매번 클릭 + 복사/붙여넣기 | **자동** (페이지 방문만 하면 됨) |
| 누가 언팔했나? | 매번 비교해야 알 수 있음 | 자동 감지 |
| 교차 매칭 | 매번 동기화 필요 | 자동 |

## 설치 (개발자 모드, 1분)

스토어 등록 없이 본인 크롬에 바로 로드 가능합니다.

1. 크롬 주소창에 `chrome://extensions/` 입력
2. 우측 상단 **개발자 모드** 토글 ON
3. **압축해제된 확장 프로그램 로드** 버튼 클릭
4. 이 폴더 (`/Users/orange/개발/naver-influencer/extension`) 선택
5. 끝. 툴바 우측에 **N** 아이콘이 나타납니다.

## 사용법

### 1) 최초 1회: ninfle.kr 로그인 토큰 자동 캡처
- 그냥 평소처럼 [ninfle.kr](https://ninfle.kr) 에 로그인하세요.
- 좌측 하단에 "✓ N인플 확장 프로그램 연결됨" 알림이 잠깐 뜨면 끝.
- 확장 프로그램은 Supabase 세션 토큰을 `chrome.storage.local` 에 보관하고, **팬 데이터를 업로드할 때만** `Authorization: Bearer …` 로 ninfle.kr API에 보냅니다. 제3자 도메인으로 토큰을 보내지 않습니다.

### 2) 매일: 본인 인플루언서 홈만 들르세요
- `https://in.naver.com/[본인 ID]` 방문
- 1.5초 후 자동으로 백그라운드 동기화 시작
- 화면 우상단에 결과 토스트가 잠깐 표시됨
- 30분 쿨다운으로 같은 페이지를 여러 번 방문해도 중복 호출 안 함

### 3) 수동 동기화
- 툴바 N 아이콘 클릭 → "지금 동기화" 버튼

## 작동 원리 (요약)

```
┌─ in.naver.com/[ID] ────────────────┐
│ content-naver.js                    │
│  → window.__PRELOADED_STATE__ 읽음  │
│  → /home/api/v2/.../subscribes/...  │
│    네이버 자체 쿠키로 페이징 fetch   │
│  → 정규화된 JSON 생성                │
└──────────────┬──────────────────────┘
               │ chrome.runtime.sendMessage
               ▼
┌─ background.js (service worker) ────┐
│ Authorization: Bearer <token>       │
│ POST ninfle.kr/api/my/fans/upload   │
└─────────────────────────────────────┘
```

## 프라이버시
- 네이버 비밀번호는 절대 다루지 않습니다 (브라우저 쿠키 그대로 사용).
- ninfle.kr 토큰은 로컬 `chrome.storage.local` 에만 저장됩니다.
- 추출된 팬/팔로잉 데이터는 ninfle.kr 본인 계정 하에만 저장됩니다.
- "연결 해제" 버튼으로 언제든 토큰 삭제 가능.

## 파일 구조

```
extension/
├── manifest.json         # MV3 메타데이터
├── background.js         # 서비스 워커 (API 호출)
├── content-naver.js      # in.naver.com 에서 스크랩
├── content-ninfle.js     # ninfle.kr 에서 토큰 캡처
├── popup.html / .css / .js  # 툴바 클릭 시 팝업
├── icons/                # 16 / 48 / 128 PNG
└── README.md             # 이 파일
```

## 트러블슈팅

| 증상 | 원인 / 해결 |
|---|---|
| 팝업 "연결 안 됨" | ninfle.kr 에 로그인 안 됨 → 로그인 후 페이지 새로고침 |
| 자동 동기화 안 됨 | 본인 페이지가 아니거나 30분 쿨다운 → "지금 동기화" 클릭 |
| HTTP 401 | 토큰 만료 → 팝업 "연결 해제" 후 ninfle.kr 재로그인 |
| 토스트가 안 뜸 | 콘솔(F12) 확인. `[ninfle-ext]` 로그가 진단 단서 |
| 네이버 페이지 로드 직후 실패 | `__PRELOADED_STATE__` 가 아직 비어있음. 1초 후 새로고침 |
