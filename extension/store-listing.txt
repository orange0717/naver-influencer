[이름]
N인플 자동 동기화

[간단 설명] (132자 이내)
네이버 인플루언서 팔로워·팔로잉을 ninfle.kr로 자동 동기화합니다. 본인 인플루언서 홈을 방문하기만 하면 백그라운드에서 갱신.

[상세 설명]
네이버 인플루언서 페이지의 팔로워·팔로잉 데이터를 ninfle.kr 대시보드로 자동 동기화하는 확장 프로그램입니다. 매번 북마클릿을 클릭하고 JSON을 복사·붙여넣기 하던 번거로움을 없애고, 본인 인플루언서 홈을 방문하는 것만으로 동기화가 끝납니다.

주요 기능:

1. 자동 동기화
   - 본인 인플루언서 홈(in.naver.com/[내 ID]) 방문 시 1.5초 후 백그라운드에서 자동 실행
   - 30분 쿨다운으로 같은 페이지 반복 방문 시 중복 호출 방지
   - 동기화 결과 토스트로 즉시 확인

2. 토큰 자동 캡처
   - ninfle.kr에 평소처럼 로그인만 하면 확장이 세션 토큰을 자동 인식
   - 토큰은 chrome.storage.local에만 저장되며 외부로 전송되지 않음
   - 별도 로그인·코드 입력 절차 없음

3. 수동 동기화
   - 툴바 아이콘 클릭 후 "지금 동기화" 버튼으로 즉시 실행 가능
   - 마지막 동기화 시각, 팔로워·팔로잉 수 팝업에서 확인

4. 언팔·교차 매칭 자동 감지
   - 매번 동기화할 때마다 ninfle.kr 서버가 변동을 자동으로 비교
   - 누가 언팔했는지, 맞팔/팬 관계가 어떻게 바뀌는지 대시보드에서 확인

사용법:
- 설치 후 ninfle.kr에 한 번 로그인하세요. "✓ 확장 프로그램 연결됨" 알림이 표시되면 준비 완료.
- 그 뒤로는 본인 인플루언서 홈(in.naver.com/[내 ID])만 들르면 자동으로 동기화됩니다.
- 툴바의 N 아이콘을 누르면 마지막 동기화 시각과 수동 실행 버튼을 볼 수 있습니다.

권한 안내:
- storage: 동기화 시각·세션 토큰 로컬 저장
- notifications: 동기화 결과 알림
- in.naver.com / gw.in.naver.com: 본인 인플루언서 데이터 읽기
- ninfle.kr / naver-influencer.vercel.app: 동기화 데이터 전송 + 토큰 자동 캡처

본 확장은 본인 계정 데이터만 다루며, 다른 사용자의 데이터에는 접근하지 않습니다.
