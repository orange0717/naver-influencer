## 1. 서비스 개요

**N인플**은 네이버 키워드챌린지·블로그 공개 데이터를 분석하여 **인플루언서 지망 블로거 및 현직 인플루언서**에게 데이터 기반 인사이트를 제공하는 SaaS 대시보드입니다.

| 항목 | 내용 |
|------|------|
| 서비스명 | N인플 (N인플루언서) |
| URL | https://naver-influencer.vercel.app |
| 운영자 | orange0717 |
| 타겟 | 네이버 인플루언서 지망 블로거 + 현직 인플루언서 |
| 가격 | 블로거 5,500원/월, 인플루언서 9,900원/월 (무료 체험 7일) |
| 운영 형태 | Next.js 16 + Supabase + Vercel 호스팅 |

## 2. 주요 기능 및 데이터 출처

각 기능은 **네이버에서 공식 제공하는 Open API**만 사용하며, **HTML 대량 스크래핑은 실시하지 않습니다**.

### 2-1. 키워드 검색량 / 경쟁도 분석

| 항목 | 내용 |
|------|------|
| 데이터 출처 | **네이버 검색광고 API** (`https://api.searchad.naver.com/keywordstool`) |
| 인증 방식 | HMAC-SHA256 서명 + API Key |
| 수집 항목 | 월간 PC/모바일 검색수, 경쟁도(LOW/MEDIUM/HIGH), 연관검색어 |
| 활용 목적 | 사용자가 입력한 키워드의 시장성·경쟁도를 시각화하여 콘텐츠 기획 지원 |
| 노출 위치 | `/keywords/[id]` 키워드 상세 페이지, 크롬 확장앱 키워드 분석 |

### 2-2. 검색 트렌드 분석 (90일)

| 항목 | 내용 |
|------|------|
| 데이터 출처 | **네이버 데이터랩 API** (`https://openapi.naver.com/v1/datalab/search`) |
| 인증 방식 | OAuth (X-Naver-Client-Id/Secret) |
| 수집 항목 | 키워드별 90일간 일별 검색 비율 (0~100 상대값) |
| 활용 목적 | 트렌드 상승/하강/유지 판정, 피크 시점 시각화 |
| 노출 위치 | 키워드 상세 페이지 90일 추이 차트 |

### 2-3. 블로거 발굴 / 순위 분석

| 항목 | 내용 |
|------|------|
| 데이터 출처 | **네이버 검색 API** (`https://openapi.naver.com/v1/search/blog.json`) |
| 인증 방식 | OAuth (X-Naver-Client-Id/Secret) |
| 수집 항목 | 블로그 ID, 닉네임, 최근 포스팅 날짜, 발견 키워드 |
| 수집 제외 | 비공개 포스트, 이메일/전화번호, 로그인 필요 페이지 |
| 활용 목적 | 활동 블로거 명단 구축, 키워드별 노출 빈도 통계 |
| 노출 위치 | `/rankings` 블로거 순위 페이지, 활동/미활동 통계 |

### 2-4. 인플루언서 점수 산정

| 항목 | 내용 |
|------|------|
| 데이터 출처 | 네이버 인플루언서 검색 결과 (공개 페이지의 챌린지 참여자 수·순위·게시글 수) |
| 수집 방식 | 사용자가 본인 인플루언서 홈을 등록할 때만 해당 인플루언서의 공개 챌린지 데이터 조회 |
| 점수 공식 | (참여자수 − 순위) × 본인 게시글 수, TOP3 한정, 본인 카테고리만 |
| 활용 목적 | 인플루언서가 자신의 키워드별 영향력을 객관적으로 확인 |
| 노출 위치 | `/rankings` 인플루언서 순위 탭 |

### 2-5. 네이버 로그인 (OAuth 2.0)

| 항목 | 내용 |
|------|------|
| 데이터 출처 | **네이버 로그인 OAuth 2.0** (`https://nid.naver.com/oauth2.0/authorize`) |
| 수집 항목 | 네이버 ID(고유 식별자), 이메일(선택), 닉네임(선택), 프로필 이미지(선택) |
| 활용 목적 | (a) 회원 식별·세션 관리, (b) 자동 회원가입(별도 비밀번호 미요구), (c) 소유 블로그·인플루언서 계정과 연결 |
| 보안 | CSRF 방지용 state 토큰, httpOnly + secure 쿠키, 30일 세션 |

## 3. 데이터 수집 정책 (투명성)

### 3-1. 공식 API 우선 원칙
- **모든 핵심 데이터는 네이버 공식 Open API로만 수집** — `polite-crawler.mjs` 헤더 주석 명시
- HTML 파싱은 데이터랩 쇼핑인사이트 인기 키워드 차트 같은 **공식 API가 존재하지 않는 일부 보조 데이터**에 한해 제한적으로 사용

### 3-2. Rate Limit 및 쿼터 준수
| 항목 | 정책 |
|------|------|
| 일일 호출 한도 | 네이버 Open API 일일 할당량의 **80% 이내**(20,000 / 25,000) |
| 요청 간격 | 최소 **250ms** (초당 4회 이하) |
| 동시성 | 키워드별 순차 처리 (병렬 호출 없음) |
| 429 응답 처리 | `Retry-After` 헤더 값 그대로 대기 후 재시도 |

### 3-3. 봇 식별
- User-Agent: `NinflBot/1.0 (+https://naver-influencer.vercel.app/bot-info)`
- 누구나 접근 가능한 **봇 정보 페이지**(`/bot-info`)에서 크롤러 정책·수집 항목·제외 요청 절차를 공개
- robots.txt 준수

### 3-4. 데이터 사용 범위
- 수집 데이터는 본 서비스의 통계·순위·분석 기능에만 사용
- **제3자 판매·재배포 금지** (개인정보처리방침 § 11 명시)
- 블로거 본인이 요청 시 **48시간 이내 데이터 삭제 + 재수집 차단 리스트 등록**

## 4. 네이버 로그인 적용 형태

- **신규 회원가입 + 기존 회원 로그인 인증** 두 가지 모두에 적용
- 네이버 로그인을 통한 가입 시 **서비스 자체 비밀번호를 별도로 요구하지 않습니다** (네이버 검수 가이드 준수)
- 가입 후 추가 정보 입력 화면 없이 바로 `/my` (본인 대시보드)로 이동
- 동일 네이버 계정 재로그인 시 새 계정 생성 없이 기존 계정 재사용

### 받는 정보의 활용
| 정보 | 활용 |
|------|------|
| 네이버 ID (고유 식별자) | 회원 식별 키 |
| 이메일 (선택) | 결제·공지 안내 (네이버 비공개 시 미수집) |
| 닉네임 (선택) | 대시보드 인사말 표시 |
| 프로필 이미지 (선택) | 헤더 프로필 아이콘 |
