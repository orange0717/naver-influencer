## A. 플랜 카드 문구 (원문 그대로)

### 무료 — `FREE` / 0원
> 회원가입(무료)으로 기본 기능을 자유롭게 이용하세요.

- MY 블로그
- 인플루언서 리스트
- 연도별 인플루언서 선정 현황
- 키워드 검색 (검색량 포함)
- 경쟁자 분석 (1일 1회)

### 예비 인플루언서 (추천)
> 인플루언서를 준비하는 블로거를 위한 플랜

- 무료 플랜 전체 포함
- MY 키워드순위
- MY 포스팅 분석
- 키워드 검색순위
- 제목 생성 (AI)
- 맞춤법 검사 *(데모 제외)*
- 커뮤니티
- 포스팅 데이터 다운로드 (1회 500건)
- 경쟁자 분석 (무제한)

### 인플루언서 — `INFLUENCER`
> 네이버 인플루언서를 위한 프리미엄 플랜

- 예비 인플루언서 플랜 전체 포함
- MY 키워드 챌린지
- 키워드 챌린지
- 블로그 글 피드백 (Claude AI)
- 포스팅 데이터 다운로드 (무제한)
- 키워드 데이터 다운로드 (1회 500건)
- 경쟁자 분석 (무제한)

## C. 운영 스펙 (원문 그대로)

| 항목 | 문구 |
|---|---|
| 데이터 갱신 주기 | 키워드 일 1회 / 인플루언서 주 1회 |
| 수집 인플루언서 | 전체 {STAT_TEXT.influencers} (활동 {STAT_TEXT.activeInfluencers}) |
| 결제 방식 | 신용/체크카드 단건 결제 (PortOne) |
| **무료 이용** | **하루 3회 (회원가입 시 매일)** |
| 결제 주기 | 1 / 3(-5%) / 6(-10%) / 9(-15%) / 12개월(2개월 무료) |
| 고객 지원 | 네이버 톡톡 / 이메일 |

🚨 이용권 페이지는 **「하루 3회」 무료 쿼터를 사용자에게 명시적으로 약속**하고 있다.
지시서 v1.2 §2.1의 「공용 쿼터 폐지」와 §3의 「이용권 페이지가 정본」이 정면으로 충돌한다 → §11-10.
