### 카드 ↔ 비교표 대조 (재추출 시점)

이전 추출에서 지적한 「경쟁자 분석 1일 1회 vs 1일 3회」 불일치는 **해소되었다**(카드에서 항목 자체가
빠지고 비교표는 `–` 로 통일).

✅ **비교표에만 있던 유료 3건**(키워드 추천 · 글감 찾기 · 릴스·쇼츠 분석)도 2026-09-02 에 인플루언서
카드로 옮겨 적었다. **이제 비교표의 유료 항목 중 카드가 안 파는 것은 없다.**

| 구분 | 항목 |
|---|---|
| 카드에만 있음 | 노출 현황 · 네이버 메이트 / N인플 AI 대화 · 블로그 기본 분석 (하루 10회) |
| 비교표에만 있음 | 동시 로그인 기기 (계정 스펙이라 카드에 적지 않는다) |

「카드에만 있음」 3건은 **무료 플랜 카드의 항목**이라 비교표의 유료 대조 대상이 아니다.
「동시 로그인 기기」는 기능이 아니라 계정 스펙이어서 비교표에만 둔다 — 둘 다 의도된 차이다.

| 데이터 갱신 주기 | 키워드 일 1회 / 인플루언서 주 1회 |
| 수집 인플루언서 | 전체 {STAT_TEXT.influencers} (활동 {STAT_TEXT.activeInfluencers}) |
| 결제 방식 | 신용/체크카드 단건 결제 (PortOne) |
| **무료 이용** | **무료 기능은 회원이면 제한 없이 · AI 대화와 블로그 기본 분석은 비회원 3회 / 회원 10회 (매일)** |
| 결제 주기 | 1 / 3(-5%) / 6(-10%) / 9(-15%) / 12개월(2개월 무료) |
| 고객 지원 | 네이버 톡톡 / 이메일 |

이전 추출에서 지적한 「하루 3회」 무료 쿼터 약속은 **문구가 교체되어 해소**되었다. 현재 페이지는
「무료 기능은 회원이면 제한 없이」 + 「AI 대화와 블로그 기본 분석은 비회원 3회 / 회원 10회」로,
쿼터가 걸리는 범위를 AI·기본 분석으로 한정해 고지한다.
