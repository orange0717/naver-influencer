 N인플 키워드 분석 - 크롬 웹스토어 등록 정보
=======================================

[이름]
N인플 키워드 분석

[간단 설명] (132자 이내)
네이버 검색 페이지에서 키워드 검색량, PC/모바일 비율, 경쟁도, 연관검색어를 한눈에 확인하세요. 글자수세기 기능도 포함되어 있습니다.

[상세 설명]
네이버에서 키워드를 검색하면 검색결과 상단에 키워드 분석 슬림바가 자동으로 표시됩니다.

주요 기능:

1. 키워드 검색량 분석
   - 월간 검색량 (총합 / PC / 모바일)
   - PC와 모바일 검색 비율
   - 경쟁도 (낮음 / 중간 / 높음)

2. 연관검색어
   - 검색한 키워드와 관련된 키워드 최대 10개
   - 각 연관검색어의 검색량 표시
   - 클릭하면 해당 키워드로 바로 검색

3. 글자수세기
   - 텍스트 입력 시 자동 표시
   - 타자수 / 글자수 / 공백제외 글자수
   - 한글 타자수 정확 계산 (초성+중성+종성)

사용법:
- 네이버에서 아무 키워드나 검색하면 자동으로 분석 슬림바가 표시됩니다.
- 슬림바를 클릭하면 상세 분석 패널이 펼쳐집니다.
- 텍스트를 입력하는 곳에서는 글자수 위젯이 자동으로 나타납니다.
- 팝업에서 각 기능을 ON/OFF할 수 있습니다.
